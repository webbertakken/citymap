# Specs

Follow the references below only as needed; never upfront.

- ./001-project-vision/vision.md - when you need the why: problem, audience, value
- ./002-project-scope/scope.md - when deciding what is in, later or out, or which repositories to test on
- ./003-system-architecture/architecture.md - when deciding where code lives, how data flows, or which tools run
- ./003-system-architecture/blueprints/README.md - when implementing the Rust CLI or proving its parity
- ./004-interface-design/viewer.md - when working on how people see and use the city: the viewer, its layout and
  separate towns switches, the bundled cities and their variants
- ./004-interface-design/blueprints/README.md - when implementing the viewer
- ./006-ground-plan/ground-plan.md - when working on districts, streets, blocks, lots, edges, the plat, separate towns
  or submodules
- ./006-ground-plan/blueprints/README.md - when implementing the ground plan engine
- ./007-local-repositories/local-repositories.md - when opening a repository from the machine: a picked folder
- ./007-local-repositories/blueprints/README.md - when implementing opening a local repository in the viewer
- ./008-buildings/buildings.md - when working on buildings, measures (size, tested, history, submodules' files) and
  their channels
- ./008-buildings/blueprints/README.md - when implementing measures, the Buildings view or colour by
- ./009-exploration/exploration.md - when working on going down into the city: walking, vehicles, physics, cameras,
  models
- ./009-exploration/blueprints/README.md - when implementing the walk, its physics, its vehicles or its models
