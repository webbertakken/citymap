# Defaults ledger

One row per value the viewer spec leaves silent or qualitative.

| Default                   | Value                                                                                                                                                                                                                                                     | Provenance                                                                                                                                                                                 | Safe range                |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------- |
| Pan per arrow key         | `PAN_SHARE` 0.1 of the view                                                                                                                                                                                                                               | common map keyboard step                                                                                                                                                                   | 0.05 to 0.25              |
| Zoom per `+`/`-`          | `KEY_ZOOM` 1.25                                                                                                                                                                                                                                           | four presses about double the scale                                                                                                                                                        | 1.1 to 1.5                |
| Zoom per wheel step       | `WHEEL_ZOOM` 1.1                                                                                                                                                                                                                                          | smooth on a notched wheel                                                                                                                                                                  | 1.05 to 1.25              |
| Fitted city               | `FIT_SHARE` 0.9 of the map                                                                                                                                                                                                                                | a margin so outlines never touch the edge                                                                                                                                                  | 0.8 to 0.95               |
| Click or tap              | moves under `CLICK_SLOP` 4 px                                                                                                                                                                                                                             | a steady press, not a drag                                                                                                                                                                 | 2 to 8 px                 |
| Hover card width          | 280 to 360 px, never more than the map less 16 px                                                                                                                                                                                                         | a 40-character path on two lines; a card, not a panel                                                                                                                                      | fixed                     |
| Hover card gap            | `CARD_GAP` 16 px from the pointer, `CARD_MARGIN` 8 px inside the map                                                                                                                                                                                      | clear of a cursor's 16 px hotspot box; the 4 px grid                                                                                                                                       | 8 to 24 px; 4 to 16 px    |
| Card row label            | 88 px column                                                                                                                                                                                                                                              | "In this folder" at 12 px on one line                                                                                                                                                      | 72 to 112 px              |
| Address number            | the index plus 1 ("No. 4" for index 3)                                                                                                                                                                                                                    | house numbers start at 1; the stored index starts at 0                                                                                                                                     | fixed                     |
| Copied feedback           | `COPIED_MS` 1,500 ms                                                                                                                                                                                                                                      | long enough to read one word                                                                                                                                                               | 1,000 to 3,000 ms         |
| Title card status         | two lines reserved (36 px)                                                                                                                                                                                                                                | the longest status (about 60 characters) at 300 px                                                                                                                                         | fixed                     |
| Device pixel ratio        | at most 2                                                                                                                                                                                                                                                 | spec (phones)                                                                                                                                                                              | 1 to 2                    |
| Start theme               | Night atlas when the system prefers dark, else Paper atlas                                                                                                                                                                                                | spec                                                                                                                                                                                       | fixed                     |
| Panel's districts         | the twelve largest top-level, wards left out                                                                                                                                                                                                              | readable without scrolling on a laptop                                                                                                                                                     | 8 to 20                   |
| GitHub requests in flight | `IN_FLIGHT` 4, when a tree is read folder by folder                                                                                                                                                                                                       | gentle on GitHub; linux reads in about 14 s                                                                                                                                                | 2 to 8                    |
| Vitals budgets            | LCP under 2.5 s, CLS 0, INP under 200 ms on a 4× slowed phone                                                                                                                                                                                             | spec, Core Web Vitals "good"                                                                                                                                                               | fixed                     |
| Search: shortest query    | `MIN_QUERY` 2 characters                                                                                                                                                                                                                                  | one character matches most of a city                                                                                                                                                       | 1 to 3                    |
| Search: hits shown        | `MAX_HITS` 7                                                                                                                                                                                                                                              | spec: at most seven choices                                                                                                                                                                | 5 to 7                    |
| Fly to a hit              | `FLY_SHARE` 0.4 of the map's shorter side, over `FLY_MS` 300 ms                                                                                                                                                                                           | the hit stands out with its neighbours seen                                                                                                                                                | 0.2 to 0.6; 150 to 400 ms |
| Smallest place flown to   | `FLY_MIN_EXTENT` 6 u                                                                                                                                                                                                                                      | a block's short side, so neighbours show                                                                                                                                                   | 4 to 12 u                 |
| Towns in the drawer       | `TOWNS_SHOWN` 7, by lots                                                                                                                                                                                                                                  | spec: at most seven choices                                                                                                                                                                | 5 to 7                    |
| Label must fit its land   | `LABEL_FIT` 0.6 of the text's width                                                                                                                                                                                                                       | a name may overhang its district a little                                                                                                                                                  | 0.4 to 1                  |
| Repeated name distance    | `REPEAT_PX` 240 px                                                                                                                                                                                                                                        | two same names a hand apart read as one                                                                                                                                                    | 160 to 400 px             |
| Glass                     | 88 % opaque, 12 px blur                                                                                                                                                                                                                                   | text keeps AA contrast over any map colour                                                                                                                                                 | 80 to 95 %                |
| Control height            | 48 px for touch, 40 px for a pointer                                                                                                                                                                                                                      | spec: 48 and 32 px floors                                                                                                                                                                  | at or above floor         |
| Interface font            | Inter variable, self-hosted (OFL-1.1)                                                                                                                                                                                                                     | spec: self-hosted; clear at 12 to 14 px                                                                                                                                                    | fixed                     |
| Icons                     | lucide-react (ISC), 20 px, stroke 1.8                                                                                                                                                                                                                     | spec: self-hosted, one consistent set                                                                                                                                                      | fixed                     |
| Search settles            | `SETTLE_MS` 600 ms before a query is logged                                                                                                                                                                                                               | a pause in typing, not every keystroke                                                                                                                                                     | 300 to 1,000 ms           |
| Free map                  | top 100 px (156 px from 1,100 px down), right 352 px with the drawer; phone 140 and 64 px                                                                                                                                                                 | the cards' sizes in the stylesheet                                                                                                                                                         | follows the cards         |
| Phone title width         | to 8 px short of the controls, which take 152 px on a touch screen                                                                                                                                                                                        | measured; checked by the overlap test                                                                                                                                                      | follows the controls      |
| Loading card appears      | `SHOW_AFTER_MS` 300 ms after a load begins; once shown, `HOLD_MS` 400 ms at least                                                                                                                                                                         | spec                                                                                                                                                                                       | fixed                     |
| Loading clock             | `TICK_MS` 250 ms while the card shows                                                                                                                                                                                                                     | whole seconds read smoothly                                                                                                                                                                | 100 to 1,000 ms           |
| Phase weights             | GitHub: commit 0.03, tree 0.67, manifests 0.02, lay 0.18, draw 0.1; bundled: download 0.6, parse 0.15, draw 0.25; file: download 0.1, parse 0.3, draw 0.6; local: index 0.1, folder 0.15, manifests 0.05, contents 0.15, coverage 0.05, lay 0.4, draw 0.1 | each phase's share of linux's load: the tree about 14 s live, laying 2.4 s (2.8 s on a 4× slowed phone), drawing 0.4 s (2.1 s); a local linux reads its index in about a second of its 4 s | follows the measurements  |
| Time left shown           | from `ESTIMATE_FROM` 0.1 of the bar and `STEADY_MS` 2,000 ms spent                                                                                                                                                                                        | earlier, the pace swings too much to trust                                                                                                                                                 | 0.05 to 0.25; 1 to 5 s    |
| Worker progress           | `POST_MS` 100 ms between posts                                                                                                                                                                                                                            | ten updates a second, little cloning                                                                                                                                                       | 50 to 250 ms              |
| Owner's repositories      | one page of 100, newest pushed first, kept `OWNER_TTL_MS` 10 minutes                                                                                                                                                                                      | spec; GitHub's largest page                                                                                                                                                                | 5 to 30 minutes           |
| Suggestions asked for     | after `SUGGEST_MS` 250 ms of rest                                                                                                                                                                                                                         | one request per owner while typing                                                                                                                                                         | 150 to 500 ms             |
| City places beside them   | `CITY_WITH_SUGGESTIONS` 3                                                                                                                                                                                                                                 | spec                                                                                                                                                                                       | fixed                     |
| Repository search         | 20 results, by stars, for any non-empty prefix of an owner with more than one page                                                                                                                                                                        | GitHub's first page is the hundred most recently pushed; a well-known name can lie past it                                                                                                 | 10 to 30                  |
| Unknown owner             | kept ten minutes, like an answer; other failures are asked again                                                                                                                                                                                          | a 404 does not change within minutes; spares the hourly allowance                                                                                                                          | 0 to 30 minutes           |
| File read slices          | `FILE_CHUNK` 1 MB                                                                                                                                                                                                                                         | bytes counted smoothly; a slice reads in a frame or two                                                                                                                                    | 256 kB to 8 MB            |
| Wait for a frame          | `FRAME_WAIT_MS` 100 ms, then on without one                                                                                                                                                                                                               | a hidden tab draws no frames                                                                                                                                                               | 50 to 250 ms              |
| Tooltip width             | 280 px (`.tooltip`), beside the panel; beneath its row below 760 px                                                                                                                                                                                       | the longest tooltip in four lines at 14 px                                                                                                                                                 | 240 to 320 px             |
| Toggles at start          | the engine's defaults, corridor and tiers on; not remembered between visits                                                                                                                                                                               | spec                                                                                                                                                                                       | fixed                     |
| Bundled variants          | all sixteen combinations of the four toggles per bundled city                                                                                                                                                                                             | Webber's decision (research)                                                                                                                                                               | fixed                     |
| Separations at start      | the engine's defaults, workspaces, submodules and apps on; not remembered between visits                                                                                                                                                                  | spec                                                                                                                                                                                       | fixed                     |
| Separate variants         | each toggle combination times each state of the separations a bundled city records (`separationStates`)                                                                                                                                                   | Webber's decision                                                                                                                                                                          | fixed                     |
| GitHub submodule depth    | 8 levels, as the CLI (`SUBMODULE_DEPTH`)                                                                                                                                                                                                                  | the ground plan ledger                                                                                                                                                                     | as the CLI                |
