# Ground plan blueprints

Follow the references below only as needed; never upfront.

- ./fixed-point.md - when working on numbers, units, directions, hashes, polygon geometry or the warp
- ./model.md - when working on snapshots, land use, the tree, the plat schema, the lockfile or the city model
- ./layout.md - when working on a town's cuts, pinwheels, archetypes, neighbourhoods, lots or addresses
- ./region.md - when working on towns, outlines, placement, highways or old towns
- ./toggles.md - when working on the toggles: corridor, archipelago, quarters, tiers, canals and their plat records
- ./separations.md - when working on separate towns: separations, members, nested parts, highways, the city's record
- ./fold.md - when working on the history fold, git reading, events, performance, security or tests
- ./DEFAULTS.md - when a value is not in the spec and you need its provenance
- ./COMPLETENESS.md - when checking whether the blueprints cover every category
